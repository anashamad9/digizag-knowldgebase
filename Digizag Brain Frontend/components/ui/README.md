# coss UI

Original components copied from https://coss.com/ui/r/{name}.json.
The source registry is recorded in `registry.json`.

Only import paths were mapped from `@/registry/default/` to this project's `@/components/`, `@/lib/`, and `@/hooks/` directories. Component markup, behavior, class names, and variants are unchanged. App compositions use the provided small size variants.

The neutral theme is copied from the official `colors-neutral` registry. Toast animation tokens and keyframes are copied from the toast registry. See https://coss.com/ui/docs/get-started for the manual installation workflow.
